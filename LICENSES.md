## Third-Party Libraries and Algorithms

### 1. Astronomical Calculation Algorithms
- **Source**: Jean Meeus, *Astronomical Algorithms*, 2nd Edition (Willmann-Bell, 1998)
- **Mathematical Formulations**: VSOP87 planetary theory truncated series, ELP-2000 lunar theory truncated series, and sidereal time calculations.
- **Licensing**: Public mathematical formulas freely usable for software implementation.

### 2. PySide6 (Qt for Python)
- **License**: GNU Lesser General Public License (LGPL) v3
- **Usage**: Used as dynamic runtime library for desktop user interface. Dynamic linking compliant with LGPL v3 requirements.

### 3. ReportLab
- **License**: BSD 3-Clause License
- **Usage**: Offline PDF document generation for landscape A4 birth charts.

### 4. Bundled City Geocoding Data
- **Source**: Derived from public domain geographical coordinates and standard IANA Time Zone database names. No remote network calls or commercial APIs used.
